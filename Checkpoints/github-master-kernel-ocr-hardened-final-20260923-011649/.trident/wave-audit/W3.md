## §2 ★ THE TWO DEFECTS THE DESK FOUND AND FIXED (both its own test caught)

### DEFECT A — the phantom gate could NEVER fire
```bash
CLAIM_RE="^[^:]*(complete[d]?|done|finished|implemented|added|built|landed|shipped|delivered)"
```
`^[^:]*` consumes the TYPE PREFIX and stops at the colon; the claim word must appear BEFORE it —
but this repo puts the type before the colon and the claim after. **The regex could never match a
real commit here.** Fixed to `^[a-z]+(\([^)]*\))?:[[:space:]]*...`.

### DEFECT B — the phantom gate fired on EVERYTHING
```bash
STAT=$(git diff --stat "$SHA"^.."$SHA" 2>/dev/null || git diff --stat --root "$SHA" 2>/dev/null)
```
**`--root` is not a valid `git diff` flag.** It silently returns EMPTY, so every root commit looked
like a phantom. Fixed to `git show --stat --format="" "$SHA"`.
